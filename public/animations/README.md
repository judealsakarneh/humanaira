# Rive Animations Folder

This folder contains Rive animation files (.riv) for the Humanaira platform.

## Required Files:

1. `ai-orb.riv` - Rotating AI orb for ServiceShowcase section
2. `loading-dots.riv` - Loading spinner for buttons and async actions
3. `floating-particles.riv` - Background ambient particles
4. `hero-glow.riv` - Hero section animated glow effect
5. `counter-up.riv` - Animated stats counter with motion
6. `button-hover.riv` - Interactive button hover effects

## How to Create These Animations:

See the main project file: `RIVE-ANIMATION-GUIDE.md` in the root directory for detailed instructions on creating each animation.

## Quick Start:

1. Go to [rive.app](https://rive.app)
2. Create a free account
3. Follow the guide to create each animation
4. Export as `.riv` files
5. Place them in this folder

## Need Placeholders?

The components are built to handle missing animation files gracefully with fallback loading states. You can add animations incrementally as you create them.
